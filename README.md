# 🎯 Guess the Number Game

A simple Python-based number guessing game where the player tries to guess a randomly generated number within a selected range.

## Features
- Random number generation.
- Three difficulty levels: Easy, Medium, and Difficult.
- Limited guessing attempts based on difficulty.
- Hints to indicate whether a guess is too high or too low.
- Displays the number of attempts used.
- Congratulates the player on winning or announces game over.

## How to Run
1. Make sure Python is installed.
2. Clone this repository.
3. Run the program:

   ```bash
   python main.py
